# STM32 FOC 电机位置控制

基于 **STM32F103C8T6** 和 STM32 HAL 的电机控制项目，采用 **单圈位置外环＋速度内环**串级 PID，实现目标位置控制，并通过串口与上位机交互。

## 控制架构

```text
上位机目标角度 → 位置 PID → 目标转速 → 速度 PID → Uq
                                                   ↓
电机 ← DRV8313 驱动 ← 三相 PWM ← 反 Park 变换与 SVPWM
```

AS5600 通过 I2C 提供机械角度：角度直接用于位置反馈，经差分和低通滤波得到转速反馈，同时换算为电角度参与电压调制。位置环每 **5 ms** 更新，速度环每 **1 ms** 更新。

当前为电压模式 FOC，速度环直接输出 q 轴电压指令 `Uq`，尚未加入电流闭环。

## 已实现功能

- **单圈位置控制**：对角度误差进行跨圈处理，按最短角度路径接近并保持目标位置。
- **位置与速度串级 PID**：位置环给出目标转速，速度环调节电压输出，带积分和输出限幅。
- **编码器反馈**：读取 AS5600 角度，通过角度差分和低通滤波估算转速。
- **三相 PWM 输出**：使用反 Park 变换和 SVPWM 驱动电机。
- **上位机交互**：串口设置目标角度、在线调整位置 PID 参数，并实时上报角度与转速。

串口命令为 `P/I/D/T`，其中 `T` 为相对配置零点的单圈目标位置，单位为**弧度**。当前阶段不包含多圈运动和加减速轨迹规划。

## 硬件组成

| 硬件 | 型号 / 配置 | 作用 |
| --- | --- | --- |
| 主控 | STM32F103C8T6 | 执行控制算法、读取编码器、输出 PWM |
| 电机驱动 | DRV8313 | 三相电机功率驱动 |
| 电机 | 2804 电机 | 被控对象 |
| 磁编码器 | AS5600 | 提供转子位置反馈 |
| 电源 | 12 V 可调电源 | 为驱动功率侧供电 |
| 通信 | 串口模块 | 连接上位机，进行调参与数据传输 |
